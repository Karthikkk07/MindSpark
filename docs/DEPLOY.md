# Deploying the MindSpark API

The API runs on **Render** (free web service) with **MongoDB Atlas** (free M0 cluster). Secrets are typed into the two dashboards only. They never go into the repository or a chat.

## 1. MongoDB Atlas (about 10 minutes)

1. Sign up at <https://www.mongodb.com/cloud/atlas/register> and create a free **M0** cluster. Pick a region near you, for example Mumbai.
2. **Database Access** -> *Add New Database User*: choose a username and a strong password (use *Autogenerate Secure Password*), role **Read and write to any database**. Keep the password for step 3.
3. **Network Access** -> *Add IP Address* -> **Allow access from anywhere** (`0.0.0.0/0`). Render's free tier has no fixed IP address, so the database is protected by the user and password.
4. **Clusters** -> *Connect* -> *Drivers*. Copy the connection string. It looks like
   `mongodb+srv://<user>:<password>@cluster0.xxxxx.mongodb.net/?retryWrites=true&w=majority`.
   Put the database name before the `?` and replace `<password>` with the real password:
   `mongodb+srv://<user>:<password>@cluster0.xxxxx.mongodb.net/mindspark?retryWrites=true&w=majority`.
   If the password has special characters (`@`, `:`, `/`, `#`), URL-encode them or generate one with letters and digits only.

## 2. Render (about 10 minutes)

1. Sign up at <https://render.com> with your GitHub account.
2. **New** -> **Blueprint** -> select the `MindSpark` repository. Render reads [render.yaml](../render.yaml).
3. When it asks for the secret values:
   - `MONGODB_URI`: the connection string from step 1.
   - `GEMINI_API_KEY`: your Google AI Studio key, or leave it empty to switch the AI features off.
4. Click **Apply**. The first build takes a few minutes.
5. Open `https://<your-service>.onrender.com/api/health`. It should return `{"status":"ok","db":"up",...}`.
   Then open `/api/quotes?limit=2`. The first start loads the quotes into the empty database by itself.

`JWT_SECRET` is generated by Render. Do not reuse your local one.

## 3. Point the app at the server

Build the APK with the server address:

```bash
flutter build apk --release --dart-define=API_BASE_URL=https://<your-service>.onrender.com/api
```

(For a debug build use `--debug`.) Plain `http` addresses only work in debug builds, so the server must use `https`, which Render provides.

## Things to know

- **Cold starts:** the free service sleeps after about 15 minutes without traffic. The first request after that takes 30-60 seconds. The app fetches quotes in the background at start-up, which wakes the server. If a sign-in fails right after a long break, try again after a minute.
- **Atlas free tier:** 512 MB of storage, which is plenty for this app.
- **Gemini:** the free tier has small limits that apply to the whole project, and `AI_DAILY_LIMIT` (default 10 per user per day) is enforced by the API.
- **Logs and settings:** the Render dashboard shows logs, and you can change environment variables there (`GEMINI_MODEL`, `AI_DAILY_LIMIT`, `CORS_ORIGIN`).
- **Rotating a secret:** if a password or key is ever exposed, change it in Atlas or AI Studio and update the value in Render.
